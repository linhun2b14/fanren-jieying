## 二、`combatStart` 的 19 张：五类分流（这是本次最大的一块）

| 类 | 张数 | 卡 | 搬去哪 |
|---|---|---|---|
| **① 纯常驻战力修正** | **6** | 啼魂、寒蛟、六翼霜蚣、紫灵、王蝉、蛮胡子 | → **常驻数值**（和 `passives()` 汇总同一条路），**不再占时点** |
| **② 有动作词，是真时点/可选动作** | **3** | **温天仁** → 可选动作（"在对战中**使用**，耗3法力"）<br>**凌玉灵** → 事件`投骰`·主体`我方`·阶段`前`<br>**银月** → 事件`投骰`·主体`我方`·阶段`前`（带"每回合1次"） | 温天仁 → **主动技能**（或"对战出牌阶段可选"）<br>凌玉灵、银月 → **投骰前** |
| **③ 真·对战出牌阶段的手牌** | **6** | 金光砖符、天雷子、朱雀环、青火雷、敛气术、青元剑诀 | → 事件`使用卡牌`·主体`我方`，**附加条件**="处在对战出牌阶段" |
| **④ 被 hack 的** | **3** | **阴魂丝** → 事件`对战宣告`·主体`我方`（=我被指定为目标）<br>**风灵劲** → 事件`对战宣告`（任意回合，别人发起时）<br>**虚天鼎** → 事件`使用卡牌`·主体`对方`·阶段`前`（=对方出牌那一刻打断） | → **新时点**，本次新建 |
| **⑤ 纯噪音** | **1** | **绿煌剑**（对战修正是 `+0`） | → **删掉这条**（它只有获胜时+1伤害，保留） |

**检查：6 + 3 + 6 + 3 + 1 = 19 ✅**

**分流后 `combatStart` 还剩多少？**
严格说"对战出牌阶段"这个窗口本身**要保留**（它是第③类那 6 张牌的挂点），
但它从"19 张啥都塞"变成"6 张真的对战出牌阶段"，**且不再承担常驻加成的结算**。

## 五、改名映射（卡牌数据要跟着改的部分）

## 六、改造的推荐顺序（每步都能单独跑通、不破坏现在能玩的局面）

| 步 | 做什么 | 收益 | 风险 |
|---|---|---|---|
| **1** | 修死 op（跳回合、手牌上限、血咒、玄阴、长春）+ 三目豹累加 | **7 张牌复活**，且都是"说有效果其实没有"的硬 bug | 低（局部修补） |
| **2** | 修晋升折扣两个 bug | 【娑罗珠】行为对上卡文 | 低（局部修补） |
| **3** | 建立"时点 + 主体 + 阶段"的**新写法**，但**只做零响应直通**（不弹询问） | 时点表结构就位，行为与现在完全一致 | 中（要动所有卡的 `when`） |
| **4** | 在**受伤 / 使用卡牌 / 被指定为目标**三处开打断 | 遮天钟、还阳术、阴魂丝、风灵劲、虚天鼎**复活** | 中（新交互层） |
| **5** | `combatStart` 五类分流（含 6 张常驻搬去常驻数值） | 时点表干净，加卡不再乱塞 | 中（要重验 6 张战力） |
| **6** | 锁链全面铺开（倒数 3 处之外的所有时点） | win/lose 窗口改成可互相响应 | 高（改动面最大） |

**建议至少先做 1 和 2**——这两步不改架构，纯修 bug，且都是"玩家已经能感觉到不对"的问题。
