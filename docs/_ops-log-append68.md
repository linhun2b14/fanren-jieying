# 2026-10-06（第十五件）· 前端：**同一个浏览器开两个窗口 = 两个玩家**（用户报「双方都显示我方胜利」）

> 用户原话：**「战斗结算胜利时，双方都显示我方胜利，应该是显示bug」**
> 追问后确认：两个玩家的**道号不一样**，是**同一台电脑上开了两个窗口**。

---

## 1. 先排除"结算代码写错"（把这条路径整条抓了一遍）

用真浏览器开了两个独立会话、把一场对战一路打到**分出胜负**，逐帧采样两边的 DOM：

| 位置 | 输的一方 | 赢的一方 |
|---|---|---|
| 顶部状态条 | 对战结果 · **等待获胜方结算** | 对战结果 · **你赢了，可打「获胜时」的牌** |
| 斗法弹窗"当前战况" | 南宫婉 领先 3 : 2 —— **南宫婉 获胜** | **你** 领先 3 : 2 —— **你正获胜！** |
| 对战面板高亮 | 对方 `is-winner`（金边）/ 自己 `is-loser`（置灰） | 自己 `is-winner` / 对方 `is-loser` |
| 一闪而过的横幅 | 对方名字 + 胜！ | 自己名字 + 胜！ |
| 战报 | 【对战结果】A 战胜 B！ | 同名同姓也一致（报真名） |

⇒ **结算侧逐处都是按"看屏幕的人"分视角的，没有一处写死"我方"**。所以问题不在这儿。

## 2. 真根因：两个窗口**其实是同一个座位**

`public\app.js` 的会话只存 `localStorage` —— 而 **localStorage 全浏览器只有一份**：

1. 窗口1 创建房间 → `localStorage.session = 甲`
2. 窗口2 加入房间 → **覆盖**成 `乙`
3. 窗口1 一刷新 / 一重连 → `Session.load()` 读到的是 **乙** ⇒ 窗口1 也变成乙

于是两个窗口坐的是**同一个玩家**：谁赢都是「你赢了 / 你正获胜！」——
用户看到的正是"双方都显示我方胜利"。这条被我写成了回归测试，**修前必挂**：

```
★ 刷新窗口1 后它还是「甲」   ← 修前：刷新后 窗口1 = 乙
新窗口不会顶掉正在使用的座位  ← 修前：新标签直接坐进「乙」，停在牌桌
```

## 3. 修法（`public\app.js` §3 会话持久化，改成**按窗口**存）

| 存哪儿 | 用途 |
|---|---|
| **`sessionStorage`** | **本窗口自己的座位**（刷新还在、窗口之间互不干扰）—— 关键这一条 |
| `localStorage` | 只留"最后一次用过的座位"，给**新开的窗口**兜底 |
| `localStorage` 心跳 `fanren.jieying.seat.v1.<房间>.<座位>` = `{tab, ts}` | 标记"这个座位被哪个活窗口坐着"（4s 一次心跳，12s 没心跳 = 那个窗口没了） |

- 启动时：优先本窗口那份；没有（新窗口）才看兜底那份，但**不会去抢一个正被别的活窗口坐着的座位**
  —— 此时停在大厅并说清楚：
  「这个浏览器里**另一个窗口**正坐在「甲」这个座位上（房间 XXXX）。想把本窗口当第二个玩家：
  直接取个道号、点「加入房间」即可（每个窗口各记各的座位）。」+ 按钮变成
  **「仍要进入 · 房间 XXXX（另一个窗口也在用）」**（明确表态才接管，免得想开第二个玩家的人被挡住）。
- 关窗口/刷新（`pagehide`）= 让出心跳；刷新后本窗口立刻重新认领（sessionStorage 还在）。
- 大厅那句提示也改了：**座位按窗口记**，同一个浏览器可以开多个窗口、一个窗口一个玩家。

**顺带**：结算横幅改成按视角说话 —— 赢的人看到「**你** 胜！」，其他人看到「**甲** 胜！」
（原来两边都是「甲 胜！」，名字一样时更分不清）。
