# 2026-10-06（第十六件）· 引擎+卡池：**装备在场上的发动时机**（用户点名复核）

> 用户原话：**「装备牌在场上的发动时机你再检查一遍，如绿煌剑，战胜时发动的效果被移到对战开始时就触发时点」**

---

## 1. 复核结论：确实错了，而且规则文档里早就写对了

`规则文档.md` §7.4 是用户自己的裁定：

| | 卡文**带**「装备时不消耗【法力值】」 | 卡文**没写** |
|---|---|---|
| 装备时 | 不消耗法力值 | 消耗法力值（`equipCost` 优先，否则角标） |
| **发动其效果时** | **才消耗（费用印在效果上）** | 不再消耗 |

同节还写着「效果的费用是"主动询问"的 —— **到时点时会问**」；§7.47【虚天鼎】更是这条规则的样板
（用户明确否掉了它的 `enable_equip_combat`，改成"两个效果各按卡文自己的时点发动、费用印在效果上"）。
§7.45 还留着【青元剑诀】的**标准写法**：

```json
"tiers": [
  { "realm": 1, "effects": [ { "when": "beforeMyRoll", "op": "dice_bonus", "value": 1, "cap": 6 } ] },
  { "realm": 2, "effects": [ { "when": "afterMyRoll",  "op": "reroll_dice", "value": 1 } ] },
  { "realm": 3, "effects": [ { "when": "combatStart",  "op": "combat_bonus", "value": 1 } ] }
]
```

**但 7 张装备当年被实现成"开战时统一付费启用"**（`enable_equip_combat` + 之后常驻/自动生效），
时点从"效果自己的时点"挪到了开战那一刻 —— 正是用户看到的
「**战胜时发动的效果被移到对战开始时就触发时点**」（【绿煌剑】角标 3 的费用问在开战，
赢不赢都得先付；【黑血刀】"投骰前+2"也一样）。

| 牌 | 卡文时点 | 迁移前 | 迁移后 |
|---|---|---|---|
| 【绿煌剑】 | 对战**获胜时** | 开战付 3 → 常驻自动 | **获胜结算窗口**里问「花 3 点让对方额外受 1 点伤害？」 |
| 【黑血刀】 | 投掷骰子前 | 开战付 2 → 常驻 | 我方投骰前问，付 2 点 → 骰点 +2 |
| 【青竹蜂云剑】 | 投掷骰子前 | 开战付 1 → 常驻 | 我方投骰前问，付 1 点 → 骰点 +1 |
| 【青竹蜂云剑 辟邪神雷】 | 对战中（战力 +1） | 开战付 2 → 常驻 | 我方投骰前问，付 2 点 → 本场战力 +1（`uses:2` 照旧） |
| 【金蚨子母刃】 | 出牌阶段 | 开战付 1 + 投骰前 | 我方投骰前问，付 1 点（`if.enemyRealm.higher` 条件照旧） |
| 【七鬼珠】 | 出牌阶段 | 开战付 2 → 常驻重掷 | 我方投骰前问，付 2 点 → 本场可额外投骰取大 |
| 【青元剑诀】 | 三档各自时点 | 开战付 2 → 只有炼气档常驻 | 按档次分别问（投骰前/投骰后/出牌阶段）；**它属于"没写免费句"那一类 ⇒ 装备时付角标 2、效果免费**（之前等于装备 2 + 开战 2，**双重收费**） |

迁移后全池 `enable_equip_combat` **清零**（op 仍保留给将来写卡用）。

## 2. 顺手逮到 3 个"一到窗口里发动就哑"的真 bug

这些效果以前只走**开战启用 + 常驻**那条专用通道，所以从没走过【斗法】链 —— 一迁到"时点窗口发动"
立刻暴露：

1. **`dice_bonus` 语义错**：`resolveEffect` 里它和 `combat_bonus` 合并处理，直接加到 `combat.bonus`
   （**战力**）—— 于是走窗口发动的【蓝丝剑】【金蚨子母刃】变成"战力 +1/+2"，而卡文写的是
   **骰子点数 +N**（骰点要再查表转附加战力，1→+0、2~5→+1、6→+2）。现在写进 `combat.diceBonus`。
2. **`damage` 的 `target:'loser'` 没有分支**：`resolveEffect` 的 damage 分支里 `picked` 对
   `mode==='loser'` 永远是空的 ⇒ 【绿煌剑】从链里发动**什么都不发生**（以前只有
   `runOnWinEffects()` 那条专用通道会打）。现在按本场对战的 `winnerId/loserId` 找落点。
3. **`reroll_dice` 从窗口发动不记账**：重掷在 `resolveCombat()` 里读 `combat.equipBonus[pl].rerollDice`，
   而只有"开战启用"那条通道会写它 ⇒ 【七鬼珠】【青元剑诀】筑基档**永远不重掷**。现在窗口发动时记进去。

配套的三处闸门：
- `timingResponders()`：结果窗口（`handOnly`）**放行"要付费"的场上效果** —— 免费/自动的
  win·lose 效果照旧不进链（由 `runOnWinEffects/runOnLoseEffects` 跑），付费的才摆出来问。
- `boardAskable()`：**要付费的效果一律可问**（哪怕数据上误标了 `auto`，不能默默白送）。
- `runOnWinEffects/runOnLoseEffects`：**跳过要付费的**（否则会"又自动打一次、又在窗口里问一次"）。
