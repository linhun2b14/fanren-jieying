# 2026-10-05（第十二件）· 编辑器：**批量改张数**（用户点名要）

> 用户原话："编辑器每种卡牌的张数，设置一个批量编辑，例如法术类全选所有牌张数加减一这样的设置。"

---

## 1. 做了什么

编辑器顶栏新增 **「批量张数 ▸」**（默认收起，展开状态记 localStorage，与"效果模拟 / 差异 / 平衡试跑"同一套）。
展开后是一条流水线：**先筛 → 预览 → 勾选 → 应用**。

**筛选（可叠加）**
- **牌堆**：宝物牌 / 法术牌 / 同行者 / 灵气牌 四个勾选框（另有「全选牌堆」「全不选」）；
- **境界**：全部 / 凡人 / 炼气期 / 筑基期 / 结丹期；
- **只改当前搜索结果里的**（复用左栏 `#search` 的关键字过滤）；
- **跳过"不进牌堆"（张数 0）的卡** —— 处理那批 `count=0` 的实物卡时很有用。

**操作（三选一，对勾选的卡生效）**
- **全部 ＋1** / **全部 －1** / **设为该值**（输入框，默认 3）。
- 张数**自动夹在 0..99**：－1 不会出现负数，乱填也不会写出 `NaN`（保存前的五步闸门本来也会拦）。

**预览与勾选**
- 命中多少张、其中多少张"真的会变"，写在「命中」那一行；
- 命中列表**逐张列出** `[牌堆] 【牌名】 旧张数 → 新张数`（不变的用灰字标出来）；
- 每张前面有勾选框（默认全选），另有「全选命中 / 全不选」——想排除几张就直接取消勾选。

**应用之后**
- 只改**界面上那份卡池**（不写盘）：左栏的"张数徽章 + 脏标记"、上面的四堆合计、
  差异面板（若开着）一起刷新；
- 横幅写一句人话：「批量改张数：改了 N 张卡（+M 张合计）。这是界面上那份卡池，点「保存（先校验）」才会写盘。」
- 保存时照旧跑五步闸门（结构预检 → 参数/时点 → `lint-cards` → `verify-dsl` → 牌堆自洽），
  任一不过**不写盘** —— 所以批量改过头了也拦得住。

## 2. 典型用法

| 想干的事 | 怎么点 |
|---|---|
| 法术类全部 +1 | 牌堆只勾「法术牌」→ **全部 ＋1** → **应用** |
| 全牌池薄一点（各减一） | 四个牌堆都勾 → **全部 －1** → **应用**（张数已经是 0 的会保持 0） |
| 把结果导进牌堆的那批实物卡改成 3 张 | 勾「跳过张数 0 的卡」→ 搜关键字或按境界筛 → **设为 3** |
| 只动搜索结果里的几张 | 左栏先搜（如"丹"）→ 勾「只改当前搜索结果里的」→ 操作 → 应用 |

整体 －1 回到原样、**不出现负数**、「设为 4」把法术全设成 4 张且不碰别的牌堆。
