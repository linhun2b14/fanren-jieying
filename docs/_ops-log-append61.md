## 2. 新机制（一张卡一条）

| op / 字段 | 干什么 | 卡 |
|---|---|---|
| `swap_hand` | 交换所有手牌（要指定目标） | 【换形诀】 |
| `steal_companion` | 夺取对方场上的同行者 | 【引魂钟】 |
| `free_card_this_turn` | 本回合出牌不花法力、每张自伤 N | 【七鬼噬魂术】 |
| `force_win` | 本次对战结果直接视为获胜（配 `roll_branch`） | 【大庚剑阵】 |
| `hurt_reflect` | 受伤时让**来源**受等额伤害、自身离场（auto，不进窗口） | 【刘靖】 |
| `cannot_be_targeted` | 到自己的下回合开始前不能被指定为对战目标 | 【隐灵纱】【神风舟】 |
| `block_qi_draw` | 除自己以外的人抽不到灵气（手动 + 卡牌效果都禁） | 【拘灵阵】 |
| `puppet_judge_damage` | 放傀儡 → 其他人各掷骰判定（≤5 判定者受伤、≥5 放置者受伤，5 点两边都吃），存 1 回合 | 【傀儡弓手】 |
| `ignore_enemy_equips`（常驻） | **后攻**且骰点压制 → 无视对方全部装备 | 【南陇侯】 |
| `companionSlotBonus`（字段） | 同行者位 +1；离场时额外放置的一起进弃牌堆 | 【胡月】 |
| `cardCostDiscount`（字段） | 宝物/法术牌法力消耗 -1（最低 1） | 【齐云霄】 |
| `absorb: 2`（字段） | 替你承受 2 次伤害 | 【厉飞雨】【曲魂】 |
| `learnRequires`（字段） | 学习条件：没搭配牌就放回牌堆底重抽 | 【大庚剑阵】 |
| `mana`（新条件） | `if: { mana: { lt: 3 } }` | 【龙纹四象蟠龙带】 |
| `lose_save_dice` + `mana` | 免罚**成功**才回法力 | 【罗烟步】 |
| `roll_branch` 子效果也能选目标 | 出牌前就弹选人（`effectNeedsTarget` 看进分支） | 【太妙多宝万华阵】 |

**引擎侧的落点**（改哪儿，下次好找）：
- 出牌流程 `doPlay`：免费出牌（七鬼噬魂术）、自伤反噬、`voidTurn` 立刻收回合（神风舟）、
  同行者额外位打标记（胡月）、装备分支的免费判定；
- 抽牌流程 `doChooseDraw`：学习条件循环（放回牌堆底重抽）；
- 探索 `doDrawTreasure`：`nextExploreTreasure` 的 2+1 张；
- 灵气 `gainQiCard`：**唯一**拦截点 —— 【拘灵阵】封锁时把牌放回灵气牌堆底；
- 伤害落地 `applyDamage`：`hurt_reflect` 的自动通道（与【燕如嫣】那类 auto 效果同一段）；
- 战斗结算 `finalOf` / `resolveCombat`：`ignore_enemy_equips`（按原始骰点判压制）、`forcedWin` 改判；
- 回合开始 / 结束：`noTarget`、`freeCardThisTurn`、`voidTurn`、`blockQiDraw` 的清零与递减，
  以及"仅存 1 回合"的傀儡进弃牌堆。

## 3. 还差的 2 张（诚实清单）

【青冥针】"受伤时指定**任意一位**修士受到等额伤害"、【金魁】"使场上任意 1 张宝物/法术牌无效"——
两张都要**在窗口/主动技能里选目标**这个交互，现在还没有：
- 引擎：`respondPlay(state, pl, uid, tier)` 与 `doActivate(state, pl, a)` 都不收 `target`；
- 前端：斗法弹窗里点候选 → 直接进链，没有"再选一个目标"这一步。

⇒ 与其偷偷按"默认打伤害来源"糊弄过去（卡文明写"指定任意一位"），不如**保持 count=0 不进牌堆**，
把这一条列进待办（引擎 + 前端一起做，顺带把【青冥针】的"可用 2 次"用起来）。

## 4. 顺手修的两个"卡池一干净就报红"的 lint 假红

1. **字段型实装的卡**（`absorb` / `soak` / `cardCostDiscount` / `companionSlotBonus` / `damageSave`）
   不再被算成"完全未实装" —— 【厉飞雨】【曲魂】【齐云霄】【胡月】这几张的效果本来就不写在 `effects` 里。
2. **"部分未实装"只认真的写了缺什么的 note**（`待实装|未实装|暂未实现|需要新 op|缺哪|待补`）——
   以前凡是带 note 的一律进这个桶，于是"已实装 + 写了说明"的卡也被列成未实装。

## 5. 回归测试与三处"种子漂移"的收口

新增 **`tests\batch8-cards-test.js`（81 项，已接进 `run-all.js`）**，一段一个机制：
数据形状 → 引擎行为 → 战报文案，覆盖上表每一条（含边界：5 点两边都吃伤、法力正好 3 点时不能发动、
可用次数用尽、没指定目标时拒绝打出、学习条件的两种分支）。

卡池从 266 → 280 张会让**所有靠种子决定的骰点整体漂移**（交接文档里记过同一个坑），
这一轮撞到两处，都改成**注入骰点**（`state.forcedDice`）：
- `tier-roots-test` 的 `toWinWindow()`：`seed=1 甲必胜` → 改成注入 `[6, 1]`；
- `cards-batch4-test` 的平局局：改成注入 `[3, 3]`。
另外 `interrupt-test` 里那条"低境界 + 有角标 + 有对战效果 ⇒ 必须有对战启用费"的通则断言，
按用户 2026-10-05 的**装备付费口径**收窄：只有卡文带「装备时不消耗【法力值】」的才需要那笔启用费
（【罗烟步】是"装备时付角标、效果免费"，所以正确做法就是**没有** `enable_equip_combat`）。
