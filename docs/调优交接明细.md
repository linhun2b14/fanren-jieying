## 5. 工作规范（接手者必读）

1. **effect-meta.js 是效果元数据唯一事实源**：新 op 要加进 OPS（前端自动有标签）；engineDirect 标记表示"不占时点、引擎直查"。
2. **测试风格**：纯 node 断言，`check(名称, 条件, 失败时打印)`，`process.exit(fail===0?0:1)`；setup() 造局模式照抄 tests\p0-regression-test.js；新测试要挂进 tests\run-all.js 的 ENGINE 数组。
3. **打断询问层（锁链）是核心架构**：付费/可选的效果走 event 写法（timingOfEffect），免费/自动的走 when 自动触发；写新效果先想清楚走哪条。判据（用户定的）：**需要付费的都要询问（付不起不问），不消耗法力的都自动**。
4. **用户通则**：普通同行者不替挡（只有 absorb 字段的 6 种：啼魂1/寒蛟1/铁火蚁1/钟卫娘1/离龟2/南宫婉2）；傀儡蜥蜴是宝物牌走傀儡位、每次替伤 2 法力、占位独立。
5. **改动后必跑**：`node tests\run-all.js --no-ui`；动了前端交互就加跑 UI 九测（需服务在跑：Start-Process node server\index.js，或确认 8094 已在监听）。
6. **不要踩的坑**：effectsOf() 对 tiers 卡的并集语义（不要再改回只返回档位）；combat 容器上的字段（blocked/loseSave 等）要在 ensureCombat 的键清单里注册；结果窗口/平局窗口现在是锁链（respond_play/respond_pass），不要再加 act('play') 直打通道；run-fanren.cmd 必须纯 ASCII（GBK 解析坑）。
7. **写操作纪律**：本项目服务在线上（fanren.example.com），改 server\ 下的文件会随下次重启生效——重启前跟用户打招呼；只读操作随意。
