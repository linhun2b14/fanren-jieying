# 2026-10-05~06（第十三件）· 前端：**手牌悬停放大镜**（用户点名要）

> 用户原话："前端手牌做一个鼠标指到哪张牌哪张就放大的效果，目前卡牌字面太小了，看不清。"

---

## 1. 为什么不是简单的 `transform: scale()`

手牌区是**横向滚动容器**（`.hand-zone { overflow-x:auto; overflow-y:hidden }`）——
CSS 规范里只要有一个轴不是 `visible`，另一个轴的计算值就会变成 `auto`，
所以卡片就地放大**一定被裁掉**（还会把滚动条挤出来）。

⇒ 做法是**跟着卡片走的浮层** `#hand-zoom`：指到哪张牌，就在它**上方**弹出同一张牌的
**高清大图**（卡面详情），字号整体放大一档（名字 26px、正文 14.5px / 行高 1.95）。
卡片本体同时抬起来 + 描金边（`.hover-zoom`），一眼看出"现在放大的是这张"。

浮层 `pointer-events:none` —— **绝不挡点击与拖拽出牌**（它只是"放大镜"，不是弹窗）。

## 2. 交互细节

| 行为 | 结果 |
|---|---|
| 鼠标指到一张手牌 | 80ms 防抖后弹大图（扫过一排牌时不会一路乱闪） |
| 指到另一张 | 内容跟着换（同一个浮层，不叠一堆） |
| 移出手牌区 / 手牌区滚动 / 窗口缩放 | 立刻收起 |
| 开始拖拽 / 按下鼠标（含点手牌） | 立刻收起（免得挡住选目标） |
| 手牌重绘（有人抽牌、出牌、状态更新） | 收起（免得显示一张已经不存在的牌） |
| **触屏设备** | 不绑定（判据见下） |
| 打不出去的牌 | **照样能放大**，并在大图底部写明"当前不可打出：<原因>" |

**触屏判据**：只看 `(hover: none)` 不够 —— **无头浏览器（CDP 跑 UI 测试）也会报 hover:none**，
但它既没有粗指针也没有触摸点。所以条件是「`hover:none` **且**（`pointer:coarse` **或** 有触摸）」才算触屏；
CSS 那边同样写成 `@media (hover: none) and (pointer: coarse)`。
