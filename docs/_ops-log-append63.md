## 1. 行动 / 抽取阶段挂机兜底（**最容易咬人的那条**）

以前只有对战与打断窗口有超时，**行动阶段挂机 = 全桌永久卡死**。现在：

- 引擎新增纯函数 **`E.autoIdleAction(state)`** → 返回 `{pid, action}` 或 null：
  抽灵气阶段 → 自动抽灵气；探索阶段 → 自动抽宝物；抉择阶段 → 自动抽法术；行动阶段 → 自动结束回合。
  有窗口 / 有对战 / 等玩家挑弃牌时**返回 null**（那些各有自己的看门狗，且不能替他挑弃牌）。
- 服务端 `armWatchdog()` 按 `ACTION_TIMEOUT_MS`（默认 **90 秒**，可用环境变量覆盖）计时，
  以 `room.lastActAt`（每次 `/api/action` 刷新）为基准；到点前会**再确认一次**局面没动过才代打。
- 代打的动作带 `auto: '<在做什么>'`，引擎在战报里写「**〔超时〕XX 长时间没有动作，系统自动…**」——
  玩家一眼看得出这是系统兜底，不是有人乱出牌。

## 2. 伪丹期收尾（【血凝五行丹】）

卡文"持续 2 回合。回合结束若没有达到结丹期，则回到筑基期，且自身受到 1 点伤害"，
以前只写了 `pseudoRealm.turns = 2` **从来没人递减** → 伪丹期永久。现在在 `endTurn` 里：

- 每过**自己的一个回合结束**递减 1，并在战报里报"还剩 N 个回合"；
- 归零时：**没到结丹期**（`realm < 3`）→ 境界退回**筑基期** + `syncEquipTiers` + 自身受 `penalty`（默认 1）点伤害；
  已结成金丹 → 平稳结束、不掉血。

## 3. 两处缺闸

- **对战中禁止晋升**：`doPromote` 加 `state.combat` 闸（以前能在别人打过来的对战里中途结丹）。

  （`applyDamage` 本来就拦闭关，缺的是"没说一句"和这几个不走伤害通道的 op。）

## 6. `tools\deploy-check.js`（"跑的是不是最新代码"一条命令问清）

```powershell
node tools\deploy-check.js          # 8094 游戏 + 8098 编辑器（没起的跳过）
node tools\deploy-check.js 8095 8097
```
读 `/api/version`（游戏）或 `/api/healthz`（编辑器），同时给两重判据：
① 服务自报的 `stale`（进程启动时哈希 vs 现在磁盘哈希）；② 进程 `started` vs 仓库最新源码 mtime。
旧进程会 **exit 1** 并直说"该重启"。
> 坑：别在脚本里 `process.exit()` —— Windows 上还有 fetch 句柄没关完，
> 直接退会触发 `Assertion failed: !(handle->flags & UV_HANDLE_CLOSING)` 崩掉；改成设 `process.exitCode`。

## 7. ②c：**舍弃类效果醒目确认** + **手牌拖到牌桌才打出**

**(a) 舍弃类确认（并且让玩家自己挑）**：
- 引擎 `doActivate` 收 **`a.discardUid`**：卡文写「将**任意 1 张**【宝物牌】放入弃牌堆」，
  以前引擎**替你挑第一张**符合的；现在前端把玩家挑的那张传进来（传的牌不在手里/牌堆不对直接拒）。
  不传就沿用旧行为 → 老调用方（命令行 / 自测 / 旧前端）零影响。
- `activatables()` 下发 `costDiscard` + `discardChoices`（要弃哪一堆、手里有哪几张可选）。
- 前端：发动带弃牌代价的技能时先弹 **⚠ 确认层**（标题写明"要弃置 1 张宝物牌"、副标题写明
  "这是一次**舍弃**、不可撤销"、每个候选项都标"将被放入弃牌堆"），选完才发
  `{type:'activate', uid, discardUid}`。

**(b) 拖拽出牌**：
- 手牌可拖（只有"轮到我、行动阶段、这张牌此刻打得出去"才拖得动）；
- 拖起来 → 牌桌给虚线高亮、手牌区给"丢这里＝取消"的红边；
- 丢在牌桌上 = 打出（**与点击完全同一条流程**：要选目标的牌会接着弹选人）；丢回手牌区 = 取消；
- **点击照旧能打**（移动端与无障碍靠它，回归断言守着）。
