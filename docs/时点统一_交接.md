## 5. 这一轮踩过的坑（新会话最容易重犯）

1. **`.NET` 的相对路径按进程 CWD 解析**，不是 PowerShell 的 `cd` —— `[System.IO.File]::ReadAllText('server\x.js')` 会找错目录。**用绝对路径**。
2. **PowerShell 5.1 + 中文引号**：内联脚本里 `"..."` 套中文引号必炸（本轮炸了 2 次）。含中文的脚本一律写成 `.ps1`（加 UTF-8 BOM）或改成 node 脚本再跑。
3. **`const` 有暂时性死区**：`PLAY_KEYS` 引用了后面才定义的 `PLAY_WINDOWS` → `require` 时直接抛 `Cannot access before initialization`。键表必须定义在 `PLAY_WINDOWS/COMBAT_WINDOWS` **之后**。
4. **一条效果可能同时写了 `when` 和 `event`**（过渡期手改的，如【遮天钟】）——判定要用 `timingKeys()`（全部键），不能用"主键" `timingKey()`，否则会漏。
5. **迁移自己的工具也踩过**：拆分双写法时，原 `event` 会在同一个循环里覆盖映射结果，拆出 `{event:'hurt', phase:'after'}` 这种非法组合（被 lint 拦下，已修）。
6. **改 `server\` 后编辑器（8098）也要重启**才会看到新元数据（`EVENTS` 是 require 进内存的）；重启方式：杀掉 8098 的 node，计划任务 `FanrenEditor` 自愈循环 5 秒拉起。
7. 改完数据**必须**跑 `--no-ui`；任何一步红就**先回滚**（`Copy-Item data\cards.json.bak-editor-<时间戳> data\cards.json -Force`），别把红灯留给下一轮。
